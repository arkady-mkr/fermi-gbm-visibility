# Видимость источника для Fermi GBM

Форма принимает время UTC и координаты J2000 в градусах и показывает затенение
Землей и статус обнаружения сигнала GBM. В деталях доступны данные POSHIST, состояние
SAA, наличие пригодного бина CTIME n0 и бортовые триггеры FERMIGTRIG в пределах
±60 секунд. Данные загружаются из открытого архива NASA HEASARC.

Для произвольного события совместимый триггер класса GRB отбирается в пределах
±10 с и комбинированной ошибки локализации (статистический радиус и 3,7° в квадратуре).
Это предварительное сопоставление. Форма не выполняет поиск слабых сигналов
в непрерывных данных. Для контрольных событий с опубликованным результатом
форма приводит вывод команды Fermi GBM и ссылку на GCN.

## Запуск

```sh
python -m pip install -r requirements.txt
python -m streamlit run streamlit_app.py
```

Используйте Python 3.12. Нажмите кнопку с названием GRB, затем «Проверить».
Геометрия всех примеров сверена по POSHIST на указанный момент.

| Событие | Затенение | Результат для GBM |
|---|---|---|
| GRB 260808B | Да | Прямой сигнал закрыт Землей, Fermi также в SAA. [GCN 45316](https://gcn.nasa.gov/circulars/45316), [GCN 45318](https://gcn.nasa.gov/circulars/45318) |
| GRB 231111A | Да | Прямой сигнал закрыт Землей при наличии пригодных данных CTIME n0. [GCN 34981](https://gcn.nasa.gov/circulars/34981) |
| GRB 260808A | Нет | Бортовой триггер. [GCN 45313](https://gcn.nasa.gov/circulars/45313) |
| GRB 170817A | Нет | Бортовой триггер. [GCN 21520](https://gcn.nasa.gov/circulars/21520) |
| GRB 251205A | Нет | Наземное обнаружение без бортового триггера. [GCN 43059](https://gcn.nasa.gov/circulars/43059) |
| GRB 211203A | Нет | Значимый сигнал не найден в целевом поиске, опубликованы верхние пределы. [GCN 31163](https://gcn.nasa.gov/circulars/31163) |

Для Streamlit Community Cloud укажите `streamlit_app.py` как точку входа.
