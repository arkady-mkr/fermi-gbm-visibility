# Видимость источника для Fermi GBM

Форма принимает время UTC и координаты J2000 в градусах. Она определяет
затенение Землей и состояние SAA по POSHIST, проверяет наличие пригодного бина
CTIME n0 и выводит бортовые триггеры FERMIGTRIG в пределах ±60 секунд.
Данные загружаются по HTTPS из открытого архива NASA HEASARC.

## Запуск

```sh
python -m pip install -r requirements.txt
python -m streamlit run streamlit_app.py
```

Используйте Python 3.12. Для проверки заполните пример GRB 260808B и нажмите
«Проверить». Ожидаются затенение, проход через SAA и пропуск в CTIME n0,
а также отсутствие бортовых триггеров в окне поиска.

Для Streamlit Community Cloud укажите `streamlit_app.py` как точку входа.
